# Tester roster — the CHARACTER/ITEM subset of the "@" commands (Server/StaffAccounts.cs).
#
# Same format as data/gm_accounts.txt: one character name per line, case-insensitive, #-comments and
# blank lines ignored, re-read by @reload, unioned with the NEXUS_TESTERS environment variable.
#
# A tester may rebuild their OWN character and summon things to try it with:
#
#   @lvl <1-99>      rebuild as that level: accurate stats + the matching spellbook
#   @mark <0-3>      rank on top of 99 — its stats and its secrets. Stops at Sam san: there are no mark-4
#                    spells in the game data. The rank NAMES are per path — Warrior 1 = "Il san (W)",
#                    Ju jak 1 = "Force", 2 = "Inferno", 3 = "Pandemonium" (@mark with no argument lists them)
#   @class <name>    switch path and rebuild for it. Peasant / Warrior / Rogue / Mage / Poet, or an NPC
#                    subpath (Chung ryong / Baekho / Ju jak / Hyun moo), or any rank title of one of those
#                    ("@class Inferno" = Ju jak at mark 2). NPC subpaths sit at level 99.
#   @align <name>    switch sub-alignment and rebuild the book
#   @stats / @might  set vitals and base stats directly, overriding the curve
#   @spell <name>    learn one specific spell, free
#   @item / @items / @clearinv / @iteminfo / @bind      summon and inspect items
#   @coins           add coin to the purse
#   @ride / @weapon / @hurt / @time                     the self-affecting toys
#
# Deliberately NOT included — these are GM-tier: teleporting (@warp), spawning monsters (@summon,
# @spawn, @cre, @kill, @rabbit), @reload, the user list, and the raw-protocol and sprite labs. A tester
# who breaks their own character costs nothing; everything withheld here either affects the live world
# or can crash a client.
